🔐 SECURITY NOTES

⚠️  IMPORTANT: The default secrets are placeholders!

Before using in production:

1. Update secrets in values.yaml or use --set flags:
   helm upgrade {{ .Release.Name }} . \
     --set secrets.postgresql.password=<strong-password> \
     --set secrets.minio.rootPassword=<strong-password> \
     --set secrets.auth0.domain=<your-domain> \
     --set secrets.auth0.audience=<your-audience>

2. Or use a separate values file for secrets:
   helm upgrade {{ .Release.Name }} . -f values.yaml -f secrets.yaml

3. Consider using external secrets management:
   - Sealed Secrets
   - External Secrets Operator
   - HashiCorp Vault
